# Vijay Niles' Blog

Personal blog built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme. Published to GitHub Pages at <https://www.vijayniles.com/>.

See [`docs/ONBOARDING.md`](./docs/ONBOARDING.md) for a full architecture walkthrough. All project documentation lives in [`docs/`](./docs/).

## Prerequisites

- [nvm](https://github.com/nvm-sh/nvm) (Node version is pinned in `.nvmrc`)
- Git

Hugo itself is **not** installed globally — it's pinned per-project via the `hugo-extended` npm package and runs through `npx`. This keeps the toolchain reproducible and matched to CI (Hugo Extended `0.146.0`).

## Setup

```bash
# Use the pinned Node version
nvm use

# Fetch the PaperMod theme (git submodule)
git submodule update --init --recursive

# Install the project-pinned Hugo binary into node_modules/
npm install
```

## Common commands

| Command | What it does |
|---|---|
| `npm run dev` | Start the local dev server with drafts (`hugo server -D`) at <http://localhost:1313> |
| `npm run build` | Production build into `public/` (`hugo --gc --minify`) |
| `npm run clean` | Remove build artifacts (`public/`, `resources/`, lock file) |
| `npm run version` | Print the pinned Hugo version |

> Prefer `npm run dev` over a global `hugo` so you always use the pinned version.

## Writing a post

```bash
npx hugo new posts/my-post-title.md
```

Edit the new file under `content/posts/`, add `tags`, and set `draft = false` to publish.

## Deployment

Push to `main`. GitHub Actions (`.github/workflows/hugo.yml`) builds and deploys to GitHub Pages automatically. The `public/` folder is generated by CI and is **not** committed to the repo.
